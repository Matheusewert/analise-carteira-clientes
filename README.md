# Análise de Carteira de Clientes

## Objetivo
Analisar uma carteira fictícia de clientes e encontrar oportunidades de cross sell.

## Funcionalidades
- Calcula o saldo total e o saldo médio da carteira.
- Lista clientes com saldo alto que ainda não têm investimento.

## Tecnologias
- Python 3

## Como executar
```bash
git clone https://github.com/Matheusewert/analise-carteira-clientes.git
cd analise-carteira-clientes
python analise.py
```

## Exemplo de saída
```
Clientes: 5
Saldo total: R$ 310000.00
Saldo médio: R$ 62000.00
Oportunidades (saldo acima de R$ 50.000 e sem investimento):
- Cliente C
- Cliente E
```

## Observação
Os dados são fictícios, criados apenas para estudo.
